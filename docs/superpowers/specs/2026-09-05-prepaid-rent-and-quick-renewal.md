# 202 本月租金折抵與房客卡片快速續約

**日期：** 2026-09-05（Asia/Taipei）
**產品分類：** V2.0 Production 正確性修正與營運入口改善

## 目標

修正已在簽約時收取本月租金、但本月帳單已先建立的房客仍被列為未繳的情況，並讓即將到期或已到期房客可從房客名單直接進入續約表單。

## 規則

1. 只有合約明確保存 `initial_rent_paid_month` 等於帳單月份，且
   `initial_rent_paid_amount` 大於零時，才可自動折抵。
2. 新帳單與既有未繳帳單都套用同一筆租金折抵；折抵金額不超過該筆帳單租金。
3. 折抵只減租金，電費、設備耗損費、管理費與其他費用仍照原規則計算。
4. 既有已繳帳單維持鎖定，不因合約快照而重算或改寫。
5. 折抵結果寫入房東帳單與房客明細，保留原房客可見備註並追加可追溯的折抵說明。
6. 房客卡片只有在有現行合約且合約為 60 天內、30 天內或已到期時顯示「快速續約」。
7. 快速續約沿用現行房客、房間、物件與合約 ID，進入既有 append-only 新版租約流程，不建立第二個房客或覆寫舊合約。

## 不在範圍

- 不直接修改正式 202 帳單或其他房客資料；部署後由房東在帳務頁送出一次既有月份更新，觸發權威計算。
- 不新增 API route、Sheet 欄位或 migration。
- 不改變 LINE／LIFF 登入、房客通知或已繳帳單鎖定規則。
