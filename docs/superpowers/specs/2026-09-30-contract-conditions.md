# 新租約與續約的補充條件

房東可在簡易新租約與既有房客續約時輸入選填、最多 500 字的補充條件（如現場狀況或新的約定）。條件寫入既有 `V2_contracts.terms_snapshot_json` 的專用版本標記，與新產生的 `contract_id` 綁定；不能從歷史 `note`、`landlord_note` 或舊版標記推定本次條件。續約不預填前約備註，房東要沿用須重新輸入。不改既有租約、正式 Sheet schema 或固定 Google Docs 範本。房客簽署前的完整合約預覽與產生的簽署版文件必須顯示同一段文字；空白不增加條款。若範本已有 `{{備註}}`，只取代該位置；沒有佔位符時，把「補充約定」加入合約正文、簽名區之前。若無法確定簽名前插入位置，就拒絕含條件合約的建立及簽署版產生。不得把沒有簽署的草稿說成已生效合約。

本次只建立本機候選與回歸證據。正式發布、Production 資料／Properties／範本修改及真人簽署驗收分開處理。
