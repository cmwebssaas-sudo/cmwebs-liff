# 合作工單 LINE 測試串接設計

日期：2026-10-08（Asia/Taipei）。狀態：待設計審閱；尚未實作或部署。
建議模型／速度：gpt-5.6-terra／medium。

## 目的與授權

合作公司或個人使用 LINE 登入，完成成員綁定後收到詢價、派工及驗收通知，並操作現有報價與完工流程。使用者已指定並授權使用 `@mmz7030n`、停用旧 Dialogflow 串接並改接工單測試服務。
此為 V3 隔離測試切片，不改動 V2 正式租管、正式帳務或其他官方帳號。

## 已核對的狀態

- 官方帳號名稱為 redbox 美拍美印，帳號 ID 為 `@mmz7030n`。
- Messaging API 已啟用。舊 Dialogflow URL 仍保存，Use webhook 開關經瀏覽器確認為關閉。
- 本機工單僅有示範登入及本機收件匣；沒有真實 LINE 登入或推播。
- 公開 HTTPS 工單測試服務、對應 LINE Login channel、Provider 配對及測試收件人尚未核實；不得借用其他帳號的現有測試服務。

## 接入方式

採獨立 HTTPS staging 服務與隔離資料儲存。沿用工單 domain 的權限與狀態轉移，新增身分驗證與通知 adapter。相比暫時公開本機 tunnel，staging 有可追溯版本與穩定回呼；相比共用現有服務，可避免干擾其他 LINE 測試。
部署前核實具體專案、網址、儲存及 LINE channel 配對。無隔離資源時停止雲端部署，保留本機測試成果。

## 身分綁定

1. 房東建立邀請，伺服器保存邀請 token 的雜湊、工作區、合作對象、預定職責、到期時間及使用狀態；邀請可撤銷。
2. 對方以 LINE Login 授權，伺服器驗證登入交易 state、nonce 與 LINE token；不得相信前端提供的 UID 或角色。
3. 核對 Login 與 Messaging API 同一 Provider 的身份範圍；不相符時不得以姓名或電話猜測對應。
4. 對方確認綁定後，房東確認成員身份及職責才啟用 membership。轉寄連結不能直接取得管理者或施工權限。
5. 每次存取重新檢查 membership、workspace 與工單指派；停用成員立即失去權限。session 使用安全 HttpOnly cookie，不將 token 放瀏覽器儲存。

## Webhook 與通知

- webhook 在解析事件之前驗證原始 request body 的 LINE 簽章；驗證失敗拒絕。
- webhook event 去重；follow 只記錄好友狀態，不自動建立有權限成員；unfollow 停止對該身份推播。
- 通知與工單事件以可恢復交易保存，提交後 worker 才發送。
- 預設發送關閉；只允許明確指定且已驗證綁定的測試 UID。禁止 broadcast、multicast 與向舊好友名單批量送出。
- 詢價給有權限的管理者或個人；施工通知給被指派成員；聯絡窗口依偏好唯讀接收。房東通知需獨立核實測試身份。
- 訊息僅含中性工種與登入入口，不包含房客資料、精確地址、門鎖資訊或附件。
- 固定重試鍵防重；超時標記結果未知，不生成新的發送重試鍵盲目補送。記錄已保存、待發送、API 已接受、失敗或未知；API 接受不代表人員已收到或閱讀。
- 通知連結導向工單，但每次登入仍需授權，網址不能直接授予權限。

## 介面

合作設定加入「邀請 LINE 綁定」、綁定／待確認／已停用狀態。廠商登入後只看自己的詢價與工單，沿用中文簡化報價、施工回報與驗收畫面。未綁定、邀請逾期及無權限皆使用明確中文提示。

## 設定與驗證

密鑰僅存伺服器 secret storage；不寫 Git、公開資產或執行日誌。設定區分測試 OA、Login channel、Provider、回呼 URL、webhook URL、指定測試 UID 及發送開關。
先以注入的 LINE adapter 測試邀請到期／重放／撤銷、state／nonce 驗證、跨工作區拒絕、成員停用、簽章偽造、webhook 去重、收件人白名單及超時防重。執行既有回歸、`npm run validate` 與 diff 檢查。
實際驗收需指定人員完成 LINE 登入、加入好友、綁定確認、收到一次通知、提交報價及完工回報；與本機／HTTP 證據分開記錄。

## 上線順序與還原

先部署發送關閉的獨立測試入口，驗證簽章与權限；再把 `@mmz7030n` webhook 改為已驗證入口並啟用。只有指定測試人員完成綁定後才進行一次測試通知。
還原先關閉發送 worker，再關閉 webhook；保留舊 Dialogflow URL 及測試資料。不得自行恢復舊 webhook 啟用狀態，因核對時原本已關閉。
