## Blockers and failed checks

### Landlord runtime matrix — BLOCKED

The landlord contracts read path threw an Apps Script Spreadsheet service exception before the isolation assertion executed:

```text
workspaceLandlordResolveAccess_
→ workspaceEnsureLegacyLandlordContext_
→ workspaceSetFirstExistingOrCreate_
→ workspaceHeaderMap_
```

The failing path was reached by `getLandlordContractsByLineUid_()` in `V2_CONTRACTS.gs`. The observed error was a Spreadsheet service access failure while reading a document. This is not evidence of cross-workspace leakage, but it prevents approval of the landlord A/B isolation matrix. It is a staging release blocker because a nominally read-only landlord route reaches legacy-context work that is not reliably available.

Required staging-only follow-up:

1. Diagnose why `workspaceEnsureLegacyLandlordContext_()` is reached during a landlord read.
2. Ensure a read route does not require legacy-context mutation or unavailable Spreadsheet access.
3. Recreate new disposable fixtures and rerun both A and B landlord allow/deny cases.

## Decision

**Overall: FAIL / NO-GO for workspace-isolation release evidence.**

Do not use this phase as Production isolation approval. Resolve and rerun those two areas with new disposable fixtures; Production remains out of scope until then.
