LINE 官方帳號設定

把租管功能接到您自己的 LINE 官方帳號，房客不用再加別的帳號。

正在確認登入…

1. 開始前請先確認

  • Provider 選了就不能改。官方帳號開通 Messaging API 時要選一個 Provider（提供者），之後無法變更或取消。下一步的 LINE Login 頻道必須建在同一個 Provider，否則系統無法傳訊息給登入的人。
  • 訊息會用您的官方帳號發送，費用算在您的方案。台灣方案（2026/11/1 起，未稅）：輕用量 0 元、每月 200 則；中用量 1,000 元、3,000 則；高用量 1,400 元、6,000 則，可加購。
  • CMWebs 會把官方帳號的 Webhook 接到系統。如果您已經接了其他聊天機器人，會被取代；系統會記下原本的網址，停用時可以改回。
  • 您原本的自動回覆與聊天設定不會被更動。

2. 在 LINE 後台準備兩個頻道

  1. 到 LINE 官方帳號管理後台 → 設定 → Messaging API，按「啟用」並選擇 Provider。
  2. 到 LINE Developers 後台，在同一個 Provider 下開啟 Messaging API 頻道：記下 Channel ID、Channel secret，並在「Messaging API」頁簽發長效的 Channel access token。
  3. 在同一個 Provider 新增一個 LINE Login 頻道，記下 Channel ID 與 Channel secret，並把頻道狀態切成「已發布（Published）」，否則房客無法登入。
  4. LIFF 不用自己建，CMWebs 會在 LINE Login 頻道自動建立。
